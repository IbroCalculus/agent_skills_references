# Rad Widgets to HTML Tag Mapping

| Rad Widget | HTML DOM Tag Rendered |
| :--- | :--- |
| `Division(...)` | `<div class="..." style="...">` |
| `Span(...)` | `<span>` |
| `Heading1(...)` | `<h1>` |
| `Paragraph(...)` | `<p>` |
| `Button(...)` | `<button>` |
| `Anchor(...)` | `<a href="...">` |
| `ListView(...)` | `<div class="...">` (scrollable container) |
